# Firmware

Каркас. Структура каталогов опережает содержимое: код появляется после фиксации состава оборудования.

- `main/` - точка входа и главный цикл
- `components/gnss/` - приём и разбор навигационных сообщений
- `components/imu/` - опрос инерциального блока
- `components/esc/` - формирование сигнала управления приводом гребного винта
- `components/steer/` - рулевое управление
- `components/rc_in/` - приём канала управления
- `components/filter/` - оценка положения и курса
- `components/control/` - управление
- `components/safe/` - отказные режимы
- `components/hal/` - вывод на периферию
- `components/board/` - назначения выводов
