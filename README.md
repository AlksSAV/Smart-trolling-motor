# Smart Trolling Motor

Электронный якорь для лодки: при активации удержания мотор удерживает лодку в заданной позиции.

## Состав

- `docs/` - концепция, требования, архитектура, риски, план испытаний, журнал, ADR
- `firmware/` - прошивка
- `hardware/` - перечень оборудования, пинмап, разводка, BOM
- `tools/` - служебные утилиты
- `sim/` - модель для отладки без железа

## Статус

Каркас. Состав оборудования и содержимое документов не определены - см. `hardware/equipment.md`.
