# Smart Trolling Motor

Электронный якорь для лодки: при активации удержания бесщёточный мотор (ESC) удерживает лодку в заданной позиции. Мотор установлен на носу, поворачивается сервоприводом на 45 градусов в каждую сторону от диаметральной плоскости.

## Статус проекта
✅ Базовый фреймворк реализован и успешно собран.
🚧 Требуется тестирование оборудования и настройка PID.

## Структура кода
- `src/main.cpp` — точка входа: IMU (BNO085), GNSS (NEO-M10N), LEDC PWM для ESC и серво, конечный автомат режимов и логика удержания
- `src/ekf_heading.*` — EKF курса: состояние `[yaw, gyro_bias]`, предсказание от IMU 20 Гц, коррекция от GNSS COG 5 Гц; матрицы 2×2 вручную, без зависимостей. **Не проверено на железе**, Q/R — заглушки
- `src/config.h` — пины и параметры, используется только `rc_receiver`; `main.cpp` его не включает и держит свои константы
- `src/rc_receiver.*` — чтение сигналов с пульта HotRC DS650 (каркас, в прошивку пока не интегрирован)
