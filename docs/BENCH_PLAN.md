# Bench plan

> Испытания без лодки. Порядок: стенд, методика, критерий приёмки, результат.

## B0 Стенд
Оснастка, оснастка привода, способ имитации воды, способы измерения.

## B1 Привод и руление
Диапазон ШИМ, мёртвая зона, гистерезис, нейтраль, время выхода на режим, ток.

## B2 Приёмник
Порог срыва, время восстановления, поведение при удержании передатчика в руке.

## B3 Оценка положения
Стационарный шум, повторная запускаемость, реакция на встряску.

## B4 Потребление
По режимам, при штатном и просаженном напряжении.

## B5 Контроллер
Поведение при просадке питания, при срыве тактовой частоты.
