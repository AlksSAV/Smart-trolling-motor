# AGENTS.md

## Правила

1. **Ничего не выдумывать.** Нет данных — пиши «не знаю». Не подставляй правдоподобные значения.
2. **Проверяй, а не предполагай.** Про «должно работать» не говорить. Говорить только то, что увидел в выводе команды.
3. **Делать ровно то, о чём просили.** Не создавать файлы, абстракции, тесты и «заготовки на будущее» без просьбы.
4. **Не трогать чужое.** Не переписывать файл целиком, не «улучшать» соседний код, не удалять молча.
5. **Спросить, если неясно.** Один вопрос дешевле переделки всего, что построено поверх догадки.
6. **Пользователь знает своё железо.** Его слова о плате — данные, а не мнение. Спорить только с выводом прибора.
7. **Кратко.** Без вступлений, итогов и пересказа того, что уже есть в файлах проекта.
