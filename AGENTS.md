# AGENTS.md

## Правила

0. **Только по команде.** Любое изменение файла, сборка, прошивка, установка пакетов,
   коммит — только после явного «делай» от пользователя. Прочитал, нашёл пробел,
   предложил — и остановился. Не «поправил заодно». Согласование спрашивается
   каждым действием отдельно, а не один раз на разговор.
1. **Ничего не выдумывать.** Нет данных — пиши «не знаю». Не подставляй правдоподобные значения.
   Порядок при пробеле: **сначала поиск в сети** (первоисточник — datasheet,
   interface description, официальный реестр пинов), **потом вопрос пользователю**.
   Молчать и подставлять «похожее на правду» число — запрещено.
   Неизвестно — значит ищем или спрашиваем, а не гадаем.
2. **Проверяй, а не предполагай.** Про «должно работать» не говорить. Говорить только то, что увидел в выводе команды.
3. **Делать ровно то, о чём просили.** Не создавать файлы, абстракции, тесты и «заготовки на будущее» без просьбы.
4. **Не трогать чужое.** Не переписывать файл целиком, не «улучшать» соседний код, не удалять молча.
5. **Спросить, если неясно.** Один вопрос дешевле переделки всего, что построено поверх догадки.
6. **Пользователь знает своё железо.** Его слова о плате — данные, а не мнение. Спорить только с выводом прибора.
7. **Кратко.** Без вступлений, итогов и пересказа того, что уже есть в файлах проекта.
8. **Документация = реальность.** TODO.md и CHANGELOG.md должны отражать только проверенные факты. Не отмечать выполненным то, что не верифицировано на железе.

## Железо и пины

Единственный репозиторий пинов — `docs/pinmap.md`. Реестр оборудования — `docs/equipment.md`.

### Ключевые компоненты
- **MCU**: ESP32-S3-N16R8 (16MB Flash, 8MB PSRAM)
- **IMU**: BNO085 (I2C, GPIO 12/13)
- **GNSS**: NEO-M10N (UART1, GPIO 17/18)
- **ESC**: Motor controller (GPIO 15, PWM 50Hz)
- **Servo**: Steering (GPIO 16, PWM 50Hz)
- **RC Receiver**: HotRC DS650 (6 PWM channels, GPIO 4-7, 10-11) — future integration

## Проверенные факты

Эти данные верифицированы на реальном железе:
- BNO085 использует I2C-адрес `0x4B` (нестандартный, типично для китайских модулей)
- NEO-M10N работает на скорости `38400 baud` (не 115200, не 9600)
- UBX-конфигурация применяется: 5Hz navigation rate + Sea dynamic model
- LEDC API ESP32 Core v3.x: `ledcAttach(pin, freq, resolution)` + `ledcWrite(pin, duty)`
- 14-bit resolution для PWM (16384 steps), 50Hz = 20ms period

## Архитектура

### State Machine
Три режима работы:
- **MODE_MANUAL**: RC receiver controls ESC and servo directly (future)
- **MODE_HEADING_HOLD**: IMU maintains current yaw, servo active, ESC neutral
- **MODE_ANCHOR_HOLD**: GNSS maintains position, both ESC and servo active

### ArduPilot Loiter Logic
- Loiter radius: 2.0m (dead zone)
- P-controller for speed based on distance
- Yaw error speed reduction: 50% speed at 90+ deg heading error
- Bearing calculation for target direction
